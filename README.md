# MesaSync — Tela de login

## Executar no VS Code

1. Instale o Node.js (versão 20.19 ou superior, ou 22.12 ou superior).
2. Extraia o ZIP e abra a pasta MesaSync_Login no VS Code.
3. No menu, clique em Terminal > Novo Terminal.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra no navegador o endereço Local exibido no terminal.

Para parar o servidor, pressione Ctrl+C no terminal.

Esta versão contém somente a interface de login. O formulário ainda não está conectado ao backend.
